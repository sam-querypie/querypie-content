# QueryPie — Reference Notes

Reference notes on QueryPie products: what each one does, which problem it addresses,
how it works, and where its boundaries are.

These documents are written for two audiences at once — people evaluating or operating
the products, and answer engines that need a clear, citable statement instead of a
marketing page. See [PRODUCTS.md](./PRODUCTS.md) for the product map.

This repository is written for people and for answer engines. Every document is meant to
stand on its own: one plain definition, the problem it addresses, the mechanism, and a
short FAQ. No marketing copy, no hashtags, no calls to action.

## Conventions

- One topic per file in [`posts/`](./posts), named `<product>-<topic>.md` by a stable slug
- Title states the question; the first sentence answers it
- `##` for the body, `###` for FAQ questions
- Statements that describe product behaviour must be reviewed before they are published
- A document's URL never changes when its content is updated

## Scope

This repository covers QueryPie products. Documents are grouped by product slug in the
filename, so the repository can grow without reorganising.

Product behaviour that has not been reviewed is not published here. Statements about
what a product does are written by the team that owns it.
